# AURELIS — Run 40 — Approval Is Not Publication

**Status:** Production-ready text brief only — not published

## Customer truth
Collector trust is weakened when an internal campaign state can be mistaken for a real-world publication event or when fictional studio personas inherit fabricated museum, award, collector, representation, or commission credentials.

The connected AURELIS Base44 build already labels artist identities as fictional Studio Personas and catalog works as AI-generated/curator-presented unless explicitly labeled otherwise. Its GitHub BUILD_STATUS.md also states that campaign functionality is a demo that creates draft proposals and approval decisions, with no posting, email send, ad purchase, analytics ingestion, or budget spend currently claimed.

## Creative strategy
**Hook:** Approval is not publication. A persona is not a biography.

AURELIS can preserve the theater of a luxury digital art house without manufacturing real-world authority.

The truthful collector journey is stronger:

Studio Persona → visual language → catalog work → AI-origin disclosure → room-context preview → material / size / license → curatorial guidance → cart decision.

Internal campaign approval should mean “ready for external handoff,” not “posted.” A reach field should not be treated as verified audience performance without external evidence.

**CTA:** Preview the work in a room, review the license, and ask Seraphina about the piece before deciding whether to add it to cart.

## Product-truth work completed in Run 40
- Changed AURELIS Campaign admin semantics so approval no longer writes or displays a false “deployed” state.
- Approval now records an approved organic/paid handoff state and explicitly says it is not publication.
- Labeled campaign reach as not independently verified.
- Replaced 16 agent-ready persona campaign drafts that contained invented real-world museum/collection/award/commission authority with transparent Studio Persona copy.
- No external post, ad spend, checkout charge, or campaign performance was claimed.

## Claims boundary
Do not claim real-world artist credentials for fictional personas, verified campaign reach without external evidence, live posting, live ad spend, live provider connectivity, or successful checkout/fulfillment unless independently verified.
